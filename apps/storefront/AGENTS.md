# What this app is

A demo-only storefront so the owner can show a customer what placing an order
and paying could look like. It is not the planned buyer app in CLAUDE.md (that
is `apps/mobile`, Expo/React Native, not built yet). See `README.md` in this
directory before assuming this becomes the real thing as-is.
